# مجموعهٔ طلایی ارزیابی ASR

این پوشه جای فایل‌های طلایی ارزیابی کیفیت رونویسی است (مراجع برنامه: ردیف W0.4 و W2.6).

## ساختار

برای هر کلیپ صوتی، دو فایل هم‌نام:

```
data/eval/
  visit-001.wav      ← صوت (wav/mp3/m4a/ogg/flac/webm)
  visit-001.txt      ← متن مرجع (رونویسی دستیِ دقیق، فارسی/انگلیسی مخلوط مجاز)
```

کلیپ‌ها عمداً در گیت نگهداری **نمی‌شوند** (حجم + رضایت‌نامهٔ داده؛ فقط همین
README مستثنی شده است). کلیپ‌های واقعی از مسیر رضایت‌محور W0.4 وارد می‌شوند.

## اجرا

```bash
# امتیازدهی با موتور محلی و مقایسه با خط مبنا
python3 scripts/eval_asr.py --engine local --verbose

# مقایسهٔ دو موتور/مدل (A/B)
python3 scripts/eval_asr.py --compare local speechmatics
python3 scripts/eval_asr.py --compare "local:whisper-large-v3-turbo" "local:shenava-koochik"

# ساخت/به‌روزرسانی خط مبنای گیت‌شده
python3 scripts/eval_asr.py --engine local --update-baseline

# BERTScore اختیاری (نیازمند نصب دستی؛ وابستگی پروژه نیست)
pip install bert-score
python3 scripts/eval_asr.py --engine local --bert-score
```

## معیارها

- **WER خام** روی توکن‌ها.
- **WER نرمال‌شدهٔ اسکریپتی**: هر دو طرف به فرم کانونی می‌روند — ارقام فارسی،
  ی/ک فارسی، حروف کوچک، حذف نیم‌فاصله و نشانه‌گذاری (نیم‌فاصله در متن معنادار
  است اما در امتیازدهی بی‌اثر؛ فقط برای نمره حذف می‌شود).
- **BERTScore** میانگین F1 با `--bert-score`. پکیج `bert-score` به‌دلیل
  وابستگی سنگینِ torch عمداً در extra های پروژه تعریف نشده و دستی نصب
  می‌شود (انحراف ثبت‌شده از طرح؛ توضیح در توضیحات PR مربوطه).

## قواعد

- خروجی غیرصفر فقط در صورت **رگرسیون** نسبت به خط مبنا (آستانهٔ پیش‌فرض
  ۰٫۵٪ مطلق، `--tolerance`).
- اسکریپت فقط با اجرای دستی کار می‌کند (وزن مدل/کلید ارائه‌دهنده لازم است)
  و عمداً در CI اجرا نمی‌شود.
- خط مبنای گیت‌شده: `docs/eval/asr_baseline.json`.
